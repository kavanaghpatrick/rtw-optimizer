- Then revised to AUD 10,065
- Should have cost $125 under Rule 16

### pandaperth vs QF: The 3-Call Battle
- QF refused free date change (should be free under Rule 16.2.a)
- Won after 3 calls with 4 browser windows of documentation open
- Had to quote exact rule text to agents who didn't know their own fare rules

### felix1224: Twitter DM Victory
- Phone agents refused free date change
- Switched to QF Twitter DMs
- Won by quoting Rule 16 text in writing
- **Lesson**: Written channels force agents to actually check rules

### CX Flights Vanishing from QF Tickets
- QF-issued tickets with CX segments
- Schedule change triggered reticketing window
- QF missed the window — CX flights silently disappeared
- Passenger discovered missing flights at check-in

### Ticket Number Roulette
- AA reissues ticket number after every minor change
- Wrong number = rejected mileage claims
- One person needed their 3rd of 5 ticket numbers to get AS credit
- **Tip**: Track ticket numbers after every single change

### The Fly-First-to-Lock-Fare Strategy (Confirmed Working)
- Multiple posters confirm: after first segment flown, base fare is permanently locked
- pandaperth, felix1224, flyhurl all used this successfully
- Book dummy dates for later segments, fly first leg ASAP, change dates for free
- **Ticket validity**: 12 months from departure date, not purchase — effective 2-year window

## 6. Lessons Learned (from the Community)

1. **Never ticket on QF** — worst service, worst knowledge, worst change handling
2. **AA RTW desk is declining** but still the best airline desk
3. **Specialist agents are worth it** for complex itineraries (£75-150 saves £500-2,000+)
4. **Fly first segment ASAP** to lock the base fare
5. **ExpertFlyer is a ceiling, not reality** — expect 30-50% of "available" segments to fail at booking
6. **Codeshares affect YQ more than availability** — use for surcharge optimization
7. **QR plating saves the most** but requires an agent
8. **Quote Rule 16 text** when airlines try to overcharge for changes
9. **Use Twitter/written channels** when phone agents refuse valid changes
10. **Track ticket numbers** after every change — mileage credit depends on it
11. **Monitor BA sales** — they trigger wholesale D-class releases
12. **Dummy dates work** — book any date with D, change for free later
13. **Surface sectors save segments** — use them strategically
14. **The online booking tool is broken** — "very buggy," use desks or agents instead

## 7. Codeshare War Stories

### Success: DONE3 with 9/16 Codeshare Segments
- "QF codes on every sector where bookable in D, AA codes on transpac (JL), transatl (QR), intra-Asia (CX)"
- Only 7 of 16 sectors on the prime carrier code — codeshare is standard practice for power users

### Success: QF Code Unlocks AA Domestic
- LAX→ORD on AA metal: AA number blocked, QF codeshare number worked
- Same physical flight, different inventory result

### Failure: Traffic Restriction Kills DXB→LHR
- AA6416 (BA-operated DXB→LHR): blocked by RTSVC traffic restriction
- AA doesn't have standalone rights for DXB→LHR — needs onward AA connection
- LHR→DXB worked under AA code, but not the reverse

### Failure: QR Refuses Non-QR Codes
- QR metal flights must be booked under QR code
- Agent tried BA codeshare on QR metal — rejected

### YQ Dodge: $850 Saved by Changing First Flight Code
- KRW 1,142,000 difference by changing first flight from JL to AA code
- First flight code can affect which carrier's surcharge rules apply to entire ticket

### YQ Dodge: $320/Segment on JNB→JFK
- BA code: ZAR 5,246 surcharge
- AA code: ZAR 2,083 surcharge
- Same seat, same plane

### Gotcha: Schedule Change Reverts Codeshare
- Carefully selected codeshare codes for YQ optimization
- Airline schedule change silently replaced codeshare with prime code
- YQ jumped — optimization undone without notification
- **Must monitor and re-request codeshare after schedule changes**

### Gotcha: Mileage Credit Varies 25%→100%
- Same L-class BA flight: 25% in QF program under BA code, 100% under QF codeshare
- AA codes earn 250% in AY program vs 125% for JL codes
- Codeshare selection directly affects status earning
